##  Questions

1. Simulate Cyclic Redundency Check (CRC) error detection algorithm for noisy channel.
2. Simulate and implement stop and wait protocol for noisy channel.
3. Simulate and implement back n sliding window protocol.
4. Simulate and implement selective reeat sliding window protocol.
5. Simulate and implement distance vector routing algorithm.
6. SImulate and implement Dijkstra algorithm for shortest path routing.
